- The user confirmed build 16 on a physical iPhone, notification receipt, and notification tap routing. Microphone/speech behavior, haptic sensation, and two-device Universal Links still have no completed physical-device evidence in this pack.

- Retention outside the app’s cleanup code, including host backups/logs and support mail, has not been established. The public policy avoids invented fixed periods.
