## Status definitions

- **Implemented + automated verification** — the repository contains the remediation and an automated unit, UI, smoke, or deterministic integration check exercises the behavior. For visual-only details, the evidence also identifies the implementation that was inspected.
- **Implemented + source inspection / partial automation** — the code remediation is present and related flows are automated, but the specifically visual or rendered detail is identified as source-inspected rather than overstated as a pixel/geometry/typeface assertion.
- **Implemented; live verification pending** — the local implementation and deterministic test path exist, but the audit explicitly requires a physical device, live service, or nondeterministic system UI to finish validation.
- **External/deployment blocker** — the local implementation exists, but credentials, Apple CDN state, or production deployment outside this workspace prevents an honest end-to-end claim.

The simulator/demo API is not treated as proof of physical share sheets, microphones, APNs, SMS delivery, Apple CDN association, or real network interruption behavior. At this review point, the repository API is newer than the deployed health surface; deployment is therefore a release gate, not an implicitly completed step.

The audit's five “remove or simplify” bullets are also accounted for rather than counted as extra rows: iPad targeting → QA-05; hidden social gate → QA-07; decorative-font scope → QA-17; uncollected phone fixture → QA-22; and keeping Share Link from being the primary remote promise until certified → MC-08 as the primary mapping, with PL-01/PL-02 as its physical/deployment follow-ups.

For readability inside the tables, bare iOS source basenames resolve to `tsutsuura/tsutsuura/`; `tsutsuuraTests.swift` and `tsutsuuraUITests.swift` resolve to their same-named files under `tsutsuura/tsutsuuraTests/` and `tsutsuura/tsutsuuraUITests/`. Bare server service basenames resolve under `server/src/Auth/`, `server/src/App/`, or `server/src/Push/` as appropriate. Migrations 005, 006, and 007 exist in both `server/migrations/sqlite/` and `server/migrations/mysql/`. Every abbreviated evidence reference therefore expands to a concrete repository path.
